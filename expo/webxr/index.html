🚀 Open AR Experience

How it works

1
Scan & Open Scan this QR code on any mobile browser — no app install needed.
2
Allow Permissions Grant camera and GPS access when prompted. Your location stays on-device.
3
Walk to a Location Approach any pinned bourbon find or speakeasy within 200 m.
4
AR Objects Appear Floating 3D bottles and location pins emerge at the real-world GPS coordinates.
5
Tap to Inspect Tap any AR object for price, brand info, and hunter notes.

Technology

Unity 2022 LTS WebXR Device API WebGL 2.0 Three.js r160 AR Foundation 5 Geolocation API DeviceOrientation API WebAssembly

Unity compiles C# AR logic to WebAssembly. The WebXR Export package replaces Unity's native XR backend with a WebXR session so the same code runs in any browser. A custom .jslib plugin bridges GPS and compass data from the browser into Unity C#.

Browser support

🤖 Android Chrome WebXR Full AR, hit-test, light estimation
iPhone Safari Fallback Camera + Three.js overlay
🦊 Firefox Fallback Camera passthrough mode
💻 Desktop Fallback 3D scene, no camera feed
